# MassFarming
 Mod to assist with large scale farming in Valheim

While holding the configured hotkey (default Left Shift, or the game's Alternate Function on controller) and using the pickup action the player will automatically harvest all pickupable items of the same type in a radius around the target. This is mainly intended for assisting with farming, but also works on world spawn pickups like rocks/sticks/berries and beehives.

Additionally, when planting crops, if the hotkey is held (default Left Shift, or Left Bumper on controller) will plant in a grid around the original target (5x5 default grid size). While the bumper is held, clicking the right/left stick steps the square grid between 3x3 and 9x9.
